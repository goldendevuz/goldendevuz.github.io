# univel — Startup Apps

Official portfolio and showcase website for **univel** — independent startup app studio by **Abdulmajid Yunus** ([@goldendevuz](https://github.com/goldendevuz)).

Live site: [goldendevuz.github.io](https://goldendevuz.github.io) · [univel.uz](https://univel.uz)

---

## Featured Apps

- **Monoblast**: Minimalist neon block puzzle for iOS.
- **Alifbek**: High-performance Uzbek Cyrillic, Classic Latin, and New Latin (Ö Ğ Ş Ç) transliteration suite and Telegram bot.

---

## Tech Stack

- Semantic HTML5 & Vanilla CSS
- Minimalist Canvas physics background animation
- Mobile-responsive, zero-dependency lightweight static site hosted on GitHub Pages
